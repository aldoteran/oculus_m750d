# Legacy Oculus M750d ROS1 Wrapper

ROS wrapper for the Oculus m750d mbes used for cool stuff at the Maritime Robotics Laboratory at KTH.

# ROS2 driver now available!

A new ROS2 driver is available [here](https://github.com/aldoteran/bpsubsea_oculus_ros2_driver).

This repo remains available for exeisting ROS1 users, but maintenance will only be supported
on the new ROS2 driver.
